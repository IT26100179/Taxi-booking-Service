TaxiGo

A comprehensive Taxi & Cab Service Booking Platform designed and developed for the SE1020 Object-Oriented Programming (OOP) module at SLIIT. Built using Java 21, Spring Boot, and robust File Handling (.txt).

Group ID: WE02 | Y1S2
System Modules
  • Passenger Management
  • Driver Management
  • Vehicle & Fleet
  • Ride Booking
  • Fare & Payments
  • Ratings & Admin
OOP Principles Employed
  • Encapsulation: Private fields & accessors
  • Inheritance: User & Vehicle hierarchies
  • Polymorphism: Dynamic Fare Calculators
  • Abstraction: FileRepository Interfaces
Persistence & Architecture

All transaction logs, fleet catalogs, driver profiles, and passenger rosters are persisted via data/*.txt file streams with thread-safe locking.
